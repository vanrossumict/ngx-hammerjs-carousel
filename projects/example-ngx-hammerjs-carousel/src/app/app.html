Features

  • Smooth swiping

    Native Pointer Events for touch, pen and mouse. The slide follows your finger, supports flicks and has a rubber band at the edges.

  • Fast

    Signals and OnPush. Pointer handling runs outside Angular's zone, so swiping never triggers application wide change detection.

  • Lazy loading

    Only the visible slide and its neighbours are loaded, and only once the carousel scrolls into view.

  • Zoneless ready

    A standalone component that works in zoneless and zone.js applications, from Angular 19 and up. This page runs without zone.js.

  • Accessible

    Real buttons, keyboard navigation (arrows, Home, End), translatable ARIA labels and support for reduced motion.

  • Themeable

    Style it with CSS custom properties: background, image fit, dot color and transition.
